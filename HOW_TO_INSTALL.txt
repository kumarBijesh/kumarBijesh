BIJESH KUMAR — ANIMATED GITHUB PROFILE
======================================

Everything needed is included in this folder:
- README.md
- assets/animated-hero.gif

HOW TO INSTALL
1. Open your GitHub profile repository:
   https://github.com/kumarBijesh
2. Upload README.md to the repository root.
3. Upload the entire assets folder to the repository root.
4. Commit the changes.
5. Refresh your GitHub profile.

IMPORTANT
- Keep the folder structure exactly like this:
    README.md
    assets/animated-hero.gif
- The README references the GIF at ./assets/animated-hero.gif.
- This animated GIF is for the README banner, not the circular GitHub avatar.
